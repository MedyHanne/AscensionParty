# AscensionParty 🎮

Un party game de course en ligne multijoueur jusqu'à 4 joueurs, développé sous Unreal Engine 5. Le but : atteindre l'arrivée en premier... ou éliminer tous tes adversaires avant qu'ils y arrivent.

---

## Gameplay

- **4 joueurs en ligne** via Steam (multijoueur en ligne)
- **2 façons de gagner** : être le premier à l'arrivée ou éliminer tous les adversaires
- **1 niveau complet** avec des zones variées aux mécaniques distinctes

### Mécaniques

| Mécanique | Description |
|---|---|
| Bumper | Propulse les joueurs dans une direction |
| Sol glissant | Réduit le contrôle du personnage |
| Grab | Attrape et projette les adversaires |
| Ralentissement | Zone qui réduit la vitesse de déplacement |
| Super Jump | Tremplin qui propulse très haut |
| Double Jump | Permet un second saut en l'air |
| Wall Jump | Permet de sauter sur les murs |

---

## Stack technique

- **Unreal Engine 5**
- **Blueprints** (logique de jeu)
- **Steam** (multijoueur en ligne via Advanced Sessions Plugin)
